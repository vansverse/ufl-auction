# Sounds

`fahh.wav` plays when one of the `fahhPlayers` (see `index.html`) is sold,
instead of that team's usual sound.

## What's here

- **`fahh.wav`** — a synthesized "fahh" vocal exclamation (0.8s, 44.1kHz mono).
  Generated by the script below, not a recording.
- **`make_fahh.py`** — regenerates `fahh.wav`. Pure stdlib, no numpy:

  ```
  python3 sounds/make_fahh.py
  ```

  Klatt-style parallel formant synthesis — a Rosenberg glottal pulse train
  through four /ah/ formant resonators (730/1090/2440/3400 Hz), with a noise
  burst for the /f/. Tweak `F0_POINTS` for the pitch contour, `AMP_POINTS` for
  loudness, `FRIC_LEVEL` for how prominent the /f/ is.

## Using the real clip instead

The original is https://www.youtube.com/shorts/TajAzT3CVJc. Save your own copy
as `sounds/fahh.mp3` — `index.html` tries the mp3 first and only falls back to
`fahh.wav`, so no code changes needed.

## If you hear nothing

Opened over `file://`, some browsers block local media loads; the page then
falls back to an in-browser Web Audio "fahh" (`playSynthFahh()`). To hear the
actual file, serve the folder:

```
python3 -m http.server 8000
# then open http://localhost:8000/index.html
```
